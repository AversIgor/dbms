# web

## Назначение и границы

Оболочка UI и карта (MapLibre). Не ходит в Postgres и не содержит серверной логики других разделов.

## Требования

- Карта и привязка — эндпоинты `api` (субъект + учётный номер ФГИС ЛК). Модель объектов — [`spatialData/CONTEXT.md`](../spatialData/CONTEXT.md).
- Статус компонентов — страница, которая читает `/health` приложений, не оркестратор.

## Ограничения и допущения

- Стек: React + Vite + MapLibre, nginx. Не gRPC.

## Интерфейсы

- **api:** HTTP, единственный прикладной backend для UI.
- **Postgres:** нет. JDBC и строки подключения в браузере запрещены.
- **Статус:** `/health` процессов `migrate`, `api`, `fgislk` и др.

## Архитектура решения

Оболочка + карта. Карта — отдельная поверхность: прикладные запросы в `api`.
